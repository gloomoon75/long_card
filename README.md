# 劇情分享小幫手(っ`ᵕ´c)

把長長的劇情文字或長圖，整理成一張一張好滑、方便分享的圖卡。

作者：懶人阿暝

---

## ✨ 功能

- **文字轉圖卡**：貼上劇情文字，自動排版並切成多張圖卡
- **長圖切割**：把一張超長的圖片切成多張
- **排版小語法**
  - `*文字*`：夾住的文字變淺色，適合對白、內心話
  - `> 文字`：行首加上，出現側邊引用線
  - `---` 或 `***`：單獨一行，變成分隔線
  - 換行會照原樣保留
- **可愛字體和手寫字體**：粉圓體、秋空圓體、丸丸泡泡體、霞鶩文楷、芫荽手寫、手帳筆記體等
- **自由調整切割線**：可以拖動、新增、移除
- **兩種存檔方式**：手機用「存到相簿／分享」，電腦用「下載圖檔」
- **注重隱私**：所有內容只在你的裝置上處理，不會上傳到任何地方

## 🚀 使用方式

1. 用瀏覽器打開 `index.html`，或前往本專案的 GitHub Pages 網址
2. 在「文字轉圖卡」貼上劇情，或在「長圖切割」上傳圖片
3. 調整字體、顏色和尺寸後，按「產生切割預覽」
4. 拖動粉紅線微調切割位置
5. 手機按「存到相簿／分享」，電腦按「下載圖檔」

> 可愛字體和手寫字體第一次使用時需要網路載入。
